Le HTML nu est la première interface de Chantilly. Chaque élément natif est stylé
selon une règle UX documentée — voici les fondations.

## Échelle typographique

Six tailles, ratio 1.25, base 16&nbsp;px. La base ne descend jamais sous 16&nbsp;px.

<div class="regle-ux">
<strong>Pourquoi 16 px minimum</strong>
C'est la taille par défaut choisie par les navigateurs — donc par les utilisateurs.
Et tout champ de formulaire sous 16&nbsp;px déclenche un zoom automatique sur iOS.
</div>

## Longueur de ligne

Les paragraphes sont limités à 65 caractères (`--measure`).

<div class="regle-ux">
<strong>Pourquoi 65 caractères</strong>
Au-delà de 70–80 caractères, l'œil perd la ligne au retour. Les études de lisibilité
convergent vers 45–75&nbsp;; Chantilly retient 65 comme équilibre.
</div>

## Interlignage

1.5 pour le corps de texte, 1.2 pour les titres — conformément au critère WCAG 1.4.12.
