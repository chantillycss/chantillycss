---
title: Installation
---
Chantilly s'installe en une balise. Aucun build, aucune dépendance, aucun JavaScript.

## Par CDN (recommandé pour commencer)

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/chantilly/dist/chantilly.min.css">
```

## Par npm

```bash
npm install chantilly
```

```css
@import "chantilly";
```

<div class="regle-ux">
<strong>Pourquoi « sans build » est une décision UX</strong>
Chaque étape d'outillage exclut des personnes. Un fichier CSS que l'on peut lire,
copier et comprendre est une interface — pour les développeurs aussi.
</div>
