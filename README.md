# Chantilly

### *Beautiful by default. Usable by design.*

Un framework CSS léger où les bonnes pratiques UX sont **encodées par défaut**.

Contrastes AA/AAA **calculés, pas promis** · cibles tactiles 44 px ·
validation bienveillante · mode sombre natif · **0 Ko de JavaScript** · sans build

```bash
npm install chantilly
```

*A lightweight CSS framework where UX best practices are encoded by default.*

---

**Les autres frameworks livrent des composants stylés.
Chantilly livre des composants corrects — chaque état, chaque règle, déjà encodés.**
